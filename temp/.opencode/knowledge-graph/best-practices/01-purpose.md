# 1. Purpose

Use this document as a reference when starting or reviewing another app that needs:

- Kotlin Multiplatform shared business logic
- clean feature modularization
- offline-first storage
- Compose-based Android UI
- native iOS UI backed by shared domain and data logic
- strong architectural boundaries that are enforced physically by modules

The source patterns in this handbook come from analyzing a modular production-style mobile codebase with shared business logic, layered architecture, and cross-platform concerns.

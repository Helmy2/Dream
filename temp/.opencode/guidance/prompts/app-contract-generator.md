# App Contract Generator Prompt

Use this prompt scaffold when generating `.mvp/app-contract.yaml` for a Dream project.

```text
Intended OpenCode agent: general

You are generating the top-level Dream app contract for a Kotlin Multiplatform MVP.

Product:
- Name: Dream
- Role: local AI app builder

Your task:
Create `.mvp/app-contract.yaml` from the user's product request.

Important:
- the user is not expected to precreate `.mvp/app-contract.yaml`
- this file is generated by Dream from the plain request

Inputs you must use:
- the user request
- `AGENTS.md`
- `.opencode/knowledge-graph/PRODUCT.md`
- relevant files from `.opencode/knowledge-graph/best-practices/`
- the selected Dream template metadata and README

Rules:
- keep the contract compact and implementation-driving
- choose explicit defaults rather than vague placeholders
- align architecture choices with Dream's modular template
- do not invent backend support unless the request implies it
- do not force persistence if the app does not need it

You must infer and record:
- app name
- app goal
- platforms
- backend choice
- storage choice
- template choice
- architecture mode
- first feature candidates
- core user outcomes

Output requirements:
- output valid YAML only
- no markdown fences
- no commentary

Minimum shape:
name: <app name>
goal: <app goal>
template: <template name>
architecture: <architecture mode>
platforms:
  - android
  - ios
iosUiStrategy: <compose_multiplatform|swiftui>
validationTargets:
  - android-cli
  - ios-cli
  - maestro-android
  - maestro-ios
backend:
  enabled: <true|false>
  type: <none|ktor|mock>
storage:
  type: <none|datastore|room|sqldelight>
features:
  - <feature name>
outcomes:
  - <primary outcome>
```

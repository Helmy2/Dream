## Findings fixed in Phase 0

- `xcodebuild test -scheme app` fails ("not currently configured for the test action"). `app.xcscheme` is regenerated by the Toolchain and has no test action; the tests live in `iosApp.xcscheme`. Eight docs, agent files and knowledge-graph files said `-scheme app` and now say `-scheme iosApp`.
- `fix-ios-project.sh` now fails if `iosApp.xcscheme` is missing or no longer lists `appTests`.
- `temp/.gitignore` ignored `.opencode/` and `AGENTS.md`, hiding Dream's own files in this repo. The ignore is removed from the template. `dream-init` already appends it to every generated project, so generated apps are unchanged.
- The root `.gitignore` now ignores `.idea/`.
- The docs hard-code the simulator `iPhone 17 Pro`, which does not exist on every machine. `verification-commands.md` now says to pick one from `xcrun simctl list devices available`.

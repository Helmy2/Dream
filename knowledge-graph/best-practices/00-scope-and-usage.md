# 0. Scope And Usage

Use this document in two ways:

- as an extraction layer: record the strongest reusable practices found in this repo
- as a drafting source: later copy, adapt, and reorganize the relevant parts into another project plan or architecture guide

When reviewing a section, classify each point mentally as one of these:

- universal practice: safe to reuse in most modern mobile projects
- KMP-oriented practice: best when sharing domain and data logic across platforms
- project-specific practice: useful as a reference, but should be adapted before reuse

Important rule for future edits:

- keep this file source-oriented and reusable
- avoid turning it into feature marketing or product-specific prose
- preserve the distinction between reusable rules and project-specific exceptions
